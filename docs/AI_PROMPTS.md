# 固定任务提示词

## 实现任务

```text
你是本项目工程师。先阅读 AGENTS.md、README.md、docs/ARCHITECTURE.md、
docs/REQUIREMENTS.md 和我指定的 docs/TASKS/TASK-NNN.md。
本次只处理这一张任务卡。
先检查当前分支和未提交改动，再给出简短执行计划。
只修改允许范围内文件，小步修改，不顺带升级依赖或重构其他模块。
遵守任务卡权限；服务器检查不代表允许部署、重启或发送真实消息。
修改后执行任务卡验证命令，检查 diff 和新增文件。
最后输出：改动摘要、实际测试结果、未验证项、风险点、建议提交信息。
不自行 commit、push、创建远端仓库、合并或发布。
```

使用前将 TASK-NNN 替换为实际任务编号，不要把模板当成已授权任务。

## 只读调查

```text
读取 AGENTS.md 和指定调查任务卡，只读核查任务范围。
分别列出已核实事实、推断、无法确认项及证据基准。
不要写入配置、安装依赖、调用业务写接口或切换服务。
历史检查结果不能代表当前状态。
```

## 人工 Review

```text
对照任务卡验收标准审查本次 diff 和新增文件。
重点检查任务外修改、密钥、权限、迁移、重复发送、数据隔离与异常路径。
核对验证命令是否真正执行，测试范围是否与结论一致。
只报告具体问题和未验证项，不把建议自动变成修改。
```
