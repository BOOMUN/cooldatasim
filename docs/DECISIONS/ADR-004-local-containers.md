# ADR-004：先本机容器部署，后迁移 AWS

- 日期：2026-10-24
- 状态：部署方向已接受；本轮数据库实现见 TASK-002。

## 背景

用户明确先部署在当前本机，后续打包镜像迁移 AWS。当前本机为 Windows，Docker 引擎运行 linux/amd64。现有模型电脑继续提供未来的模型接口，不在本轮改动。

## 决策

- 数据库使用独立 PostgreSQL 17 + pgvector 容器及命名卷，不复用其他项目数据库。
- 对应上游镜像固定 digest，定制镜像仅加入初始化 SQL，不加入数据、凭证或模型权重。
- 本机端口仅绑定 127.0.0.1:5433。管理员与应用账号使用不同随机密码，应用账号不是超级用户。
- 本轮迁移包只含数据库镜像、Compose、脚本和空凭证示例；后续应用完成后才扩充应用镜像。
- AWS 按 linux/amd64（x86_64）目标准备；ARM 实例需另行构建与验证。

## 后果

镜像包不包含命名卷内容。迁移必须分别处理镜像、数据库备份、附件及新环境密钥；不能只 docker load 就声称数据已迁移。PostgreSQL 主版本升级、生产账号权限及数据库恢复应独立 Review 和验收。本轮不配置 AWS、域名、TLS、远端模型网络或 WhatsApp。

本决策只确定数据库和部署基础；前后端技术栈及其他组件仍按 ADR-003 的提案状态推进。
