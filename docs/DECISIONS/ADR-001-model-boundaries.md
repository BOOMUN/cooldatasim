# ADR-001：Qwen 模型职责与数据隔离

- 日期：2026-10-24
- 狀態：模型分工已接受；使用者後續指定暫用 DeepSeek V4.1 Flash high 進行對話，Qwen 對話設定保留。

## 背景

用户明确要求使用服务器里的 Qwen 对话模型生成客服回复，强调不能混同向量模型。服务器另有员工知识服务，包含 CPU 上的 Embedding 和 Reranker。

## 决策

對話生成、向量檢索和重排分工獨立。Cool Data Sim 的知識、商品、會話和檢索指令獨立於員工資料。允許評估復用模型能力，不直接復用員工問答業務介面。

2026-10-24 使用者追加指定：暫用 OpenCode Go 提供的 DeepSeek V4.1 Flash，推理強度 high。新 CHAT_* 設定成組生效，不將 Qwen 憑證混用於外部供應者；向量與重排仍保留獨立的 Qwen 設定。

## 后果

需设计独立检索适配和索引；若采用已检查的 Qwen Embedding，则统一 1024 维。Qwen 对话曾返回 503，必须单独完成可用性验证。启动、切换模型或修改员工服务需要新任务授权，本决策不授权此类操作。
