# ADR-005：本机首版与真实验收边界

- 日期：2026-10-24
- 状态：按用户“确定方案并开发”授权实施，真实外部联调仍待完成。

## 背景

首要目标是网站知识与 Qwen 客服，模型接口和 WhatsApp 号码未联调。用户特别要求未完成不得标记完成。

## 决策

- Vue 3 / TypeScript / Vite + FastAPI / SQLAlchemy，PostgreSQL / pgvector；LangGraph 实际组织检索、生成和校验。
- 首版使用 PostgreSQL 持久 Job 队列与独立 worker，SELECT FOR UPDATE SKIP LOCKED 领取任务。暂不引入额外 Redis 服务；这是对原提案的收敛，避免新增无必要的运维依赖。
- 新后台从零实现；RelayDesk 仅作为行为参考，没有复制其业务源码。
- 网站内容采集为草稿。文档发布保留快照，修改草稿不替换旧快照；商品改动退回待审核。
- 向量接口未配置时只允许明确标识的关键词检索，不制造向量；Qwen 未配置时不返回假 AI 回答。
- 首版提供人工与 AI 建议模式，真实外发硬性关闭。演练数据明确标记，只允许管理员。
- 权限、认证和本机应用使用真实数据库；测试通过、真实服务联调和产品完整验收分别记录。

## 后果

源码和模拟协议测试通过不能替代 WhatsApp 真机测试。媒体传输、历史补拉、自动回复、流式通知、定时同步、文档版本回退、PDF 采集等尚未完成的能力必须列出。远端模型、AWS 和通道关联继续按独立授权处理。
