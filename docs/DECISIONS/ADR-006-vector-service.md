# ADR-006：獨立 CPU 向量與重排接口

- 日期：2026-10-24
- 狀態：使用者已授權接通，實際結果以 TASK-004 為準。

## 背景

模型電腦已有 Qwen3-Embedding-0.6B 與 Qwen3-Reranker-0.6B，但員工知識服務沒有標準模型接口。客服系統需要自己的指令、資料庫及向量索引。

## 決策

新增 cooldatasim-vector-api 使用者服務，CPU限定、單進程、僅監聽127.0.0.1:8195，以本專案獨立Bearer憑證提供模型清單、向量及重排。模型檔及已安裝Python環境唯讀復用，不匯入員工業務程式。

本機透過既有AWS跳板及模型電腦SSH通道，轉發到127.0.0.1:18082；容器使用host.docker.internal。第一跳依known_hosts驗證，第二跳固定Ed25519主機公鑰；不新增AWS公開端口或遠端轉發服務。

文件與查詢用途分開，查詢加入Cool Data Sim檢索指令；向量固定1024維並正規化。重排使用Qwen yes/no softmax，分數不視為答案正確率。

## 後果

新增進程約需數GB記憶體並使用有限CPU執行緒，設定8GB記憶體上限及8個Torch執行緒。模型接口不保存文字、不讀員工索引。實際發布的客服知識才會生成並保存向量；測試必須使用隔離資料，不自動發布網站草稿。

模型權重、API憑證和私有SSH設定不放進應用鏡像。AWS遷移時需另外建立私有連線。現階段Windows開機後需透過應用啟動命令啟動本機SSH轉發，沒有新增系統排程或更改其他模型服務。
