# TASK-NNN：任务名称

## 状态

草案，未授权执行。

## 背景

说明关联需求编号、当前问题和证据，不将参考实现当成目标项目已完成。

## 验收标准

- 写可观察的结果、异常路径和适用环境。
- 说明哪些需要真机、外部依赖或人工验收。

## 允许修改

列出仓库相对路径；用反引号包裹每个路径。填写后才可执行，禁止写“全仓库”。

## 禁止修改

任务外文件、参考克隆、服务器及其他用户未授权资源。

## 操作权限

明确本地写入、网络读取、外部写入、服务调整、提交推送分别是否允许。

## 执行计划

读取依据 → 确认范围 → 小步实现 → 验证 → 更新本卡。

## 验证命令

填写实际可执行的命令，并说明业务覆盖边界。

## 验证结果

未执行；记录命令、结果、时间与未覆盖项，不预填通过。

## 人工验收与风险

记录重点 Review 项、未解决阻碍和回滚方式。
